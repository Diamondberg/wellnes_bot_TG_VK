# Папка для исходных картинок

Положи сюда исходники от QWEN (или другого источника):

  main.png    — главный экран приветствия
  1.png       — картинка для вопроса №1
  2.png       — картинка для вопроса №2
  ...
  36.png      — картинка для вопроса №36

Принимаются: .png, .jpg, .jpeg, .webp

После добавления — запусти из корня проекта:

    python tools/optimize_images.py

Скрипт сожмёт картинки и положит результат в:

    frontend/assets/images/

Эта папка (raw_images) НЕ попадёт в git, можно хранить большие исходники.
